---

## 📖 Long Description

This project is a fully responsive Netflix Pakistan landing page clone built from scratch using only **HTML5** and **CSS3**. It replicates the look and feel of the official Netflix website with pixel-perfect accuracy.

The project was built section by section to deeply understand how a professional streaming platform structures its UI. Every section — from the hero banner to the footer — was carefully crafted to match the original design.

### 📌 Sections Included

- **Navbar** — Netflix logo with Sign In button, fixed at the top with gradient overlay
- **Hero Section** — Full-screen background with real Netflix poster mosaic image, headline text, subtitle, and email + Get Started form with smooth fade-up animations
- **Curved Divider** — Netflix signature pink/red glow curve separating the hero from content
- **Trending Now** — Horizontal scrollable card slider with 6 movie posters, large rank numbers, and prev/next navigation buttons
- **More Reasons to Join** — 4-card grid with dark purple gradient backgrounds, titles, descriptions, and SVG icons
- **FAQ Accordion** — 6 frequently asked questions with smooth slide-down animation, rotating +/× icon, and one-open-at-a-time behavior
- **Footer** — Email CTA, footer links grid (4 columns), language selector, and copyright text

### ✨ Features

- ✅ Pure HTML & CSS — no frameworks
- ✅ Fully responsive (mobile, tablet, desktop)
- ✅ Real Netflix background poster image
- ✅ Smooth CSS animations and transitions
- ✅ Interactive FAQ accordion (JavaScript)
- ✅ Horizontal card slider with scroll buttons (JavaScript)
- ✅ Netflix-accurate colors, fonts, and spacing
- ✅ Hover effects on all interactive elements
